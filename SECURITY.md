# Seguridad

No publiques vulnerabilidades, claves, datos de clientes ni archivos DWG en un
issue público. Usa un canal privado acordado con el autor.

Las huellas de equipo usadas por la beta son identificadores derivados y no
contienen archivos personales. Una licencia publicada sólo puede utilizarse en
el equipo cuyo código coincide con el documento firmado.

Nunca se publican:

- las claves privadas de actualización o licenciamiento;
- el código fuente comercial;
- credenciales administrativas;
- dibujos o datos de clientes.
